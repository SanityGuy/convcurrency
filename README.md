# ConvCurrency

A simple currency converter using the [Frankfurter API](https://github.com/frankfurter-app/frankfurter).

## Features

-   Rates are updated every time you convert.
-   Rates are updated every 10 minutes.
-   Rates are updated when you convert.
-   Rates are updated when you change the currency.
-   Rates are updated when you change the amount.
-   Rates are updated when you change the currency and amount.
